# Portafolio Web - Barac Escobar

## Secciones del portafolio

* **Inicio:** incluye presentación personal y un apartado sobre mi
* **Proyectos:** muestra proyectos en proceso y completados
* **Habilidades:** lenguajes de programación, herramientas y habilidades
* **Contacto:** medios para encontrarme y comunicarse conmigo.

## Proyecto

El portafolio puede visualizarse desde GitHub Pages:

**Enlace:** (https://baraz1.github.io/Portafolio-Web/)

## Uso de Inteligencia Artificial

Durante el desarrollo de este proyecto se utilizó **Claude, de Antrhopic**, como herramienta de creación de código.

La inteligencia artificial se utilizó principalmente para:

* Hace estructuras HTML para las secciones.
* Desarrollar el menú de navegación.
* Resolver dudas y detectar posibles errores en el código.
* Mejorar la organización y presentación de los contenidos del portafolio.

### Prompts utilizados

**1. Estructura inicial del portafolio**

Quiero crear un portafolio web utilizando HTML, CSS y JavaScript. Necesito que tenga una estructura ordenada y separada en diferentes páginas: Inicio, Proyectos, Habilidades y Contacto. Crea la estructura base de los archivos y el código necesario para comenzar el proyecto.

**2. Menú de navegación**

Crea un menú de navegación para mi portafolio utilizando HTML y Bootstrap. Quiero que permita navegar entre las diferentes páginas del sitio y que sea responsive para computadores y celulares.

**3. Diseño y organización**

Ayúdame a crear un diseño para mi portafolio utilizando Bootstrap y CSS. Quiero que todas las páginas mantengan un estilo consistente, con una buena distribución de los elementos y un diseño moderno pero sencillo.

**4. Adaptación a dispositivos**

Revisa mi código y haz los cambios necesarios para que el portafolio sea responsive. Quiero que los elementos se adapten correctamente a diferentes tamaños de pantalla, especialmente celulares, tablets y computadores, sin romper el diseño existente.

**5. Revisión y corrección del código**

Revisa el código HTML, CSS y JavaScript de mi portafolio y busca posibles errores o problemas. Mantén la estructura y el diseño que ya tengo y modifica solamente lo necesario para solucionar los problemas encontrados.
